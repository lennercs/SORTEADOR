# 🎲 DevSorteio

🔗 **Acesse o projeto online:** [Clique aqui para testar o Sorteador](https://lennercs.github.io/SORTEADOR/)

Um sorteador de números aleatórios moderno, responsivo e elegante, desenvolvido para consolidar conceitos fundamentais de lógica de programação em JavaScript, estilização avançada com CSS e boas práticas de responsividade.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do projeto.
* **CSS3:** Design moderno utilizando conceitos de Dark Mode, transições suaves, animações `@keyframes` (efeito floating no dado) e total responsividade com `@media query`.
* **JavaScript (ES6+):** Lógica de sorteio utilizando o padrão matemático universal `Math.floor(Math.random() * (max - min + 1)) + min`, Arrow Functions, tratamento de campos vazios com `isNaN` e manipulação de DOM.

## 🛠️ Funcionalidades

* **Sorteio Inteligente:** Sorteia números considerando intervalos customizados pelo usuário.
* **Validação de Segurança (Guard Clauses):** Impede o sorteio caso os campos estejam vazios ou se o valor mínimo for maior ou igual ao valor máximo, alertando o usuário com mensagens claras.
* **Controles Rápidos (+ e -):** Botões interativos para incrementar e decrementar os valores dos campos de forma simples.
* **Interface Responsiva:** Layout totalmente adaptável para dispositivos móveis e computadores através de breakpoints calculados dinamicamente.
* **Função Limpar:** Reseta os campos de input e o resultado com apenas um clique para reiniciar a experiência.
